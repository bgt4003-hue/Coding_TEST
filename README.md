# HTML/CSS/JavaScript 테트리스 게임

브라우저에서 바로 실행할 수 있는 순수(바닐라) JS 테트리스입니다.

## 실행 방법

```bash
cd /workspace/Coding_TEST
python3 -m http.server 5500
```

브라우저에서 아래 주소로 접속하세요.

```text
http://localhost:5500/index.html
```

## 주요 기능

- 10x20 보드 테트리스 플레이
- 7종 블록(I, O, T, S, Z, J, L)
- 다음 블록 미리보기
- 점수/라인/레벨 시스템
- 레벨 상승에 따른 하강 속도 증가
- 일시정지(P), 재시작 버튼

## 조작법

- `← / →` : 좌우 이동
- `↓` : 소프트 드롭
- `↑` 또는 `X` : 시계 방향 회전
- `Z` : 반시계 방향 회전
- `Space` : 하드 드롭
- `P` : 일시정지/재개
